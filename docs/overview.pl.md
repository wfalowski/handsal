# Dokumentacja

Handsal jest serwerem autoryzacji. Usługa prosi go o token. Twoje API sprawdza ten token, zanim zrobi robotę.

- [Zabezpiecz API](/pl/docs/sdk). `@handsal/sdk` robi to sprawdzenie w Hono, Express i Next.js. Artykuł w repozytorium to `docs/sdk.pl.md`.
- [Integracja](https://github.com/wfalowski/handsal/blob/main/docs/integration.md) (po angielsku). Prośba o token, reguły weryfikacji, klucze prywatne, agenci i delegacja.
- [Wdrożenie](https://github.com/wfalowski/handsal/blob/main/docs/deployment.md) (po angielsku). Kontener, PostgreSQL i publiczny adres.
- [API zarządzania](https://github.com/wfalowski/handsal/blob/main/docs/api.md) (po angielsku).
- [Agenci AI](https://github.com/wfalowski/handsal/blob/main/docs/agents.md) (po angielsku).

Te strony to pliki markdown w `docs/`. Dłuższe przewodniki też są markdownem, a linki powyżej je otwierają.
