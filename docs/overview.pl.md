# Dokumentacja

Handsal jest serwerem autoryzacji. Usługa prosi go o token. Twoje API sprawdza ten token, zanim zrobi robotę.

- [Zabezpiecz API](/pl/docs/sdk). `@handsal/sdk` robi to sprawdzenie w Hono, Express i Next.js.
- [Integracja](/docs/integration) (po angielsku). Prośba o token, reguły weryfikacji, klucze prywatne, agenci i delegacja.
- [Wdrożenie](/docs/deployment) (po angielsku). Kontener, PostgreSQL i publiczny adres.
- [API zarządzania](/docs/api) (po angielsku).
- [Agenci AI](/docs/integration#6-ai-agent-applications) (po angielsku).

Te same artykuły to pliki markdown w `docs/`.
