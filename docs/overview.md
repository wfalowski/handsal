# Documentation

Handsal is an authorization server. A service asks it for a token. Your API checks that token before it does the work.

- [Protect an API](/docs/sdk). `@handsal/sdk` does the check in Hono, Express, and Next.js.
- [Integration guide](/docs/integration). Requesting a token, the verification rules, private keys, agents, and delegation.
- [Deployment](/docs/deployment). The container, PostgreSQL, and the public URL.
- [Management API](/docs/api).
- [AI agents](/docs/integration#6-ai-agent-applications).
